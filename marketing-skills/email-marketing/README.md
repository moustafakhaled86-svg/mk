# Email Marketing Skills

Strategy, automation, and best practices for effective email campaigns.

## Email Marketing Fundamentals

### Benefits
- High ROI (average $42 per $1 spent)
- Direct communication channel
- Personalization opportunities
- Measurable results
- Scalable

## List Building

### List Sources
- Website signup forms
- Lead magnets
- Webinars
- Contests/giveaways
- Purchased lists (verify compliance)
- Social media

### Signup Best Practices
- Single opt-in vs. double opt-in
- Clear value proposition
- Minimal friction
- Mobile-friendly forms
- Privacy assurance

### List Segmentation
- Demographic data
- Engagement level
- Purchase history
- Interests/preferences
- Lifecycle stage

## Copywriting Best Practices

### Subject Lines
- 50 characters or less
- Personalization when relevant
- Create curiosity
- Action-oriented
- Test variations

### Preview Text
- First 50-100 characters visible
- Complement subject line
- Include call-to-action hint

### Body Copy
- Start with value proposition
- Short paragraphs (2-3 sentences)
- Scannable format
- Clear hierarchy
- One primary CTA

### Call-to-Action (CTA)
- Action-oriented language
- Contrasting colors
- Multiple placements
- Mobile-friendly buttons
- Clear value exchange

## Metrics & Analytics

### Key Metrics
- **Deliverability Rate**: % successfully delivered
- **Open Rate**: % of emails opened (typical: 15-25%)
- **Click Rate**: % of clicks on links (typical: 2-5%)
- **Conversion Rate**: % completing desired action
- **Unsubscribe Rate**: Keep below 0.2%
- **Bounce Rate**: Hard/soft bounces

### Advanced Metrics
- Click-to-open rate (CTR / Open Rate)
- Conversion per recipient
- Revenue per email
- List growth rate
- Spam complaint rate

## Compliance & Best Practices

### CAN-SPAM Act
- Clear sender identification
- Accurate subject line
- Visible physical address
- Clear unsubscribe option
- Honor unsubscribe within 10 days

### GDPR Compliance
- Explicit consent required
- Easy unsubscribe
- Privacy policy transparency
- Data handling
- Right to be forgotten

### Authentication
- SPF records
- DKIM signing
- DMARC policy
- Monitor sender reputation
